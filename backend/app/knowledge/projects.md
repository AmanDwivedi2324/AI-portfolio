# Projects

## YouTube AI Assistant

A conversational RAG application that allows users to ask questions
about YouTube videos and receive answers based on the video context.

Technologies:
Python, LangChain, Gemini, Pinecone, FastAPI, React.

The system extracts video transcripts, splits them into chunks,
generates embeddings, stores them in a vector database and retrieves
relevant context before generating an answer.
